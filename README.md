# Knot-A-Problem
This website can help you find crochet and knit patterns that can help you elevate your designs. With some of these designs you can get to change your fibre arts projects from looking dull to looking fabulous.

# How it works
First you are introduced to the world of tapestry crochet in the first page. 
The next page shows you three creators who can help you learn more about tapestry crochet and it also has links to their YouTube channels for easier discovery.
The following page has some simple patterns that you can select and you can start on those for practice on the different things that come with design making.
Finally, we have the feedback page. We would love to hear more from you and it would help us know how to improve.
